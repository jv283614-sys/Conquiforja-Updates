# 🏆 Conquiforja

### Sua central de jogos, conquistas e platinas para Windows!

O Conquiforja é um aplicativo para Windows que reúne sua biblioteca de jogos, conquistas, troféus, platinas e emuladores em um só lugar.

## 🎮 Funcionalidades

- Biblioteca de jogos para PC e emuladores.
- Sistema de conquistas e platinas locais.
- Integração com emuladores compatíveis.
- Notificações de conquistas durante as partidas.
- Histórico de partidas e tempo jogado.
- Metas e coleções de jogos.
- Backup de saves.
- Capturas de tela das conquistas.
- Central de atualizações.

### Como instalar

1. Acesse o link de download.
2. Na seção Assets, baixe o arquivo Setup.exe.
3. Execute o instalador no Windows.
4. Siga as instruções de instalação.
5. Abra o Conquiforja e configure sua biblioteca!

## 🔄 Atualizações

As novas versões serão publicadas neste repositório.

Estamos preparando um sistema que permitirá ao Conquiforja avisar automaticamente quando houver atualizações disponíveis.

## 🏅 Conquistas locais

O Conquiforja permite acompanhar conquistas e platinas locais, sem modificar as conquistas oficiais das plataformas.
